  1030→5.2 USER INTERFACE DESIGN PRINCIPLES
  1031→--------------------------------------------------------------------------------
  1032→
  1033→DESIGN PHILOSOPHY: "Scientific Power, Consumer Simplicity"
  1034→
  1035→Core UI Principles:
  1036→
  1037→1. PROGRESSIVE DISCLOSURE
  1038→   - Simple tasks are simple (one click to run BLAST)
  1039→   - Advanced options available but hidden by default
  1040→   - Expert users can access full parameter control
  1041→   - Never overwhelm beginners with complexity
  1042→
  1043→2. CONSISTENT PATTERNS
  1044→   - Same upload flow for every tool
  1045→   - Same results viewer layout
  1046→   - Same export/share options
  1047→   - Same keyboard shortcuts everywhere
  1048→   - Learn once, apply everywhere
  1049→
  1050→3. VISUAL FEEDBACK
